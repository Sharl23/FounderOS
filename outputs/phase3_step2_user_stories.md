# User stories and acceptance criteria

DEMO-ONLY PROTOTYPE: not validated, not launch-ready, not commercially approved.

1. As one of the undergraduate students at Cairo universities, I want to see study spaces near me so that I can stop asking around.
   - [ ] A list of demo study spaces is shown on load
   - [ ] Each card shows name, area and features
2. As one of the undergraduate students at Cairo universities, I want to search by name or area so that I find a place quickly.
   - [ ] Typing in the search box narrows the list on every keystroke
   - [ ] An empty result shows a clear message
3. As one of the undergraduate students at Cairo universities, I want to filter by the features I need so that I only see suitable options.
   - [ ] Ticking a feature shows only items that have it
   - [ ] Several features combine (AND)
4. As one of the undergraduate students at Cairo universities, I want to open details so that I can decide where to go.
   - [ ] Clicking a card opens its details
   - [ ] Details can be closed with a button or Escape
