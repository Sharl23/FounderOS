# Testing

| Layer | Command | What it proves | What it does not |
|---|---|---|---|
| Unit/integration (272 tests) | `python -m pytest -q` (repository root; tests live in `tests/`) | Safety rules (12 × fixtures), 21 criteria, five kinds, judge contract and adversarial judges, research verifier and failure paths (timeout retry, TLS, truncation, SSRF), gates and bypass attempts, OOM mapping, v0.4 and v0.7 migrations. v0.8 (`test_v08_contract.py`): all 67 rubric ids, hash and mapping; brief extraction with spans; discovery guard; relevance review; independence; absence caps; simulated tests; minors; decision log; validation prose | Real model quality; live providers |
| Real browser (82 checks, including the six-phase journey) | `python scripts/ui_e2e.py` (Playwright + Chromium) | Every screen and button against the live API and SQLite. Includes: refresh, back, deep links, the criteria matrix with judging, the relevance review, restaurant brief spans and D02, the decision log fields, hard stop, model failure, phone width, the keyboard skip link, no raw JSON, and Build → Commercial → Sell → Operate with approve/reject dialogs, sandboxed preview, replayed payment, refund and reconciliation | Uses a TEST_ONLY fake model and mocked providers |
| Live check (founder's machine) | `python scripts/live_check.py [--url https://...]` | Real inference, latency of three fresh briefs, live Crossref/OpenAlex/World Bank access | Writes only what it observed |
| Demo run (writes `outputs/`, `decision_log.json`) | `python scripts/demo_run.py [--offline]` | The real pipeline end to end on a fresh database: weak-evidence STOP, prohibited-idea stop, and all six phases with MOCKED payments | Uses the labelled STUBBED stand-in when Ollama is not reachable |
| Submission compliance | `python scripts/check_submission.py` | Every repository convention in the root `CLAUDE.md`: files, README headings, ARCHITECTURE sections, licence text, decision-log fields, output names, a STOP gate, mock labels, no tracked secrets or databases, branch `main`. It re-runs the pipeline in a temporary folder and compares the result with the committed `outputs/` and `decision_log.json` | Building the Docker image (needs Docker Hub access) |
| Manual API smoke | `python scripts/smoke.py` | Live refine + discover via HTTP | — |

All synthetic data in tests is labelled TEST_ONLY; the shipped app has no fake model and no seeded evidence. Phases 3-6 use DEMO DATA and a MOCKED payment simulator, labelled as such wherever they appear.
